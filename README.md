# Лендинг акции «Скидка за смартфон» — HTML/CSS/JS шаблон

Обновлённая посадочная страница акции Mobiuz, свёрстанная в визуальном языке
дизайн-системы МТС **«Гранат» 2.0**. Чистые HTML, CSS и JavaScript — без сборки,
фреймворков и зависимостей. Откройте `index.html` в браузере, и всё работает.

## Структура

```
index.html              — разметка страницы, SVG-спрайт иконок, микроразметка schema.org
assets/css/tokens.css   — дизайн-токены: цвета, шрифты, отступы, радиусы, тени, тёмная тема
assets/css/styles.css   — компоненты и адаптив
assets/js/main.js       — интерактив (9 независимых модулей)
```

## Дизайн-система

Все визуальные решения вынесены в `tokens.css` — это **единственный файл,
который нужно править при ребрендинге**.

```css
--mts-red:    #FF0032;   /* основной акцент */
--grey-900:   #1D2023;   /* «Ежевика» — основной текст */
--c-blueberry:#0097FD;   --c-mint:  #00C19B;
--c-banana:   #FAC031;   --c-orange:#F95721;   --c-plum: #6E4AE6;
--r-lg: 24px;            /* увеличенные радиусы «Граната 2.0» */
```

### Шрифты

Фирменные **MTS Compact** и **MTS Wide** публично не распространяются, поэтому
подключён свободный фолбэк Inter. Чтобы поставить фирменные шрифты, добавьте
`@font-face` со своими файлами — переменные `--font-wide` и `--font-text`
подхватят их автоматически, менять компоненты не нужно.

### Тёмная тема

Переопределяются только семантические роли (`--bg-page`, `--text-primary` и т. д.),
палитра бренда остаётся прежней. Выбор сохраняется в `localStorage`; пока
пользователь не выбрал тему вручную, страница следует системной настройке.
Тема применяется инлайн-скриптом в `<head>` — «вспышки» белого при загрузке нет.

## Доступность

- Семантические теги, корректная иерархия заголовков, `<dl>` для пар «значение — подпись»
- ARIA-паттерны Tabs и Accordion с навигацией стрелками, `Home` и `End`
- Ссылка «Перейти к содержимому», видимое кольцо фокуса, закрытие меню по `Esc`
- Поддержка `prefers-reduced-motion` и `prefers-contrast`
- Без JS контент остаётся читаемым (`<noscript>` отключает анимации появления)

## Как адаптировать под себя

1. **Цвета и типографика** — `assets/css/tokens.css`.
2. **Тексты, адреса, вопросы** — `index.html`, блоки размечены комментариями.
3. **Дата окончания акции** — атрибут `data-deadline` у `#countdown`
   (формат ISO 8601 с часовым поясом, например `2026-12-31T23:59:59+05:00`).
4. **Суммы в калькуляторе** — атрибуты `data-fee` у кнопок `.chip`.
5. **Иконки** — SVG-спрайт в начале `<body>`, подключаются через `<use href="#i-…">`.
6. **Микроразметка** — блок `application/ld+json` в `<head>` (Offer + FAQPage).

Чтобы FAQ раскрывался в несколько пунктов сразу, удалите блок «Режим
„аккордеон“» в модуле 05 файла `main.js` — это отмечено комментарием.
